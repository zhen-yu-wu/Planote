# planoteSync 云函数配置

1. 在微信开发者工具中上传并部署本云函数，选择“云端安装依赖”。
2. 为云函数配置环境变量 `SYNC_ACCESS_KEY_HASH`，值为同步密钥的 SHA-256 小写十六进制摘要。
3. 将 `items` 集合权限设置为“仅管理端可读写”，所有同步读写均由本云函数完成。

第一个使用主密钥验证的微信账号会写入 `sync_owner` 管理员记录。管理员随后可通过小程序创建、查看和收回带有效期的一次性分发密钥。原始分发密钥仅在创建响应中返回一次，数据库只保存 SHA-256 摘要和用于识别的脱敏尾号。密钥到期或被收回后，关联账号会立即失去同步权限。不要把原始主密钥或摘要写入小程序端代码。
