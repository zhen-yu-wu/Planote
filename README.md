# 我的日序

“我的日序”（项目代号 Planote）是一个原生微信小程序个人工作台，用来管理想法、日/周/年任务和日程。第一版完全使用微信本地 Storage，不需要服务器、账号或云数据库。

## 当前功能

- 首页按“今天 → 本周 → 长期”展示，并自动选出 3–5 条今日重点
- 日任务、周任务、年任务以及可选的年度进度
- 日程的日期、开始时间与结束时间
- 紧急程度与重要程度分别记录
- 收集箱筛选、月历查看、快速完成、编辑与删除
- 本地 JSON 备份导出与导入恢复
- 独立 Repository / Service 数据层，便于以后替换为远程 API

## 运行

1. 打开微信开发者工具。
2. 选择“导入项目”，目录指向本仓库根目录。
3. 使用测试号或在 `project.config.json` 中替换自己的 AppID。

数据保存在 `planote_items_v1` 这个本地 Storage 键中。

## 目录

```text
pages/          页面与交互
services/       业务逻辑、首页聚合与排序
repositories/   本地数据访问
utils/          日期和周次计算
```
