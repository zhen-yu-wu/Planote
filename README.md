# 我的日序

“我的日序”（项目代号 Planote）是一个原生微信小程序个人工作台，用来管理想法、日/周/年任务、琐事和日程。事项数据默认保存在微信本地 Storage 中。

## 当前功能

- 首页按“今天 → 本周 → 长期”展示，并自动选出 3–5 条今日重点
- 日任务、周任务、年任务以及可选的年度进度
- 独立琐事类型，用于记录无需优先级和截止时间的日常小事
- 日程的日期、开始时间与结束时间
- 紧急程度与重要程度分别记录
- 收集箱筛选、月历查看、快速完成、编辑与删除
- 本地 JSON 备份导出与导入恢复
- 基于微信云开发 `items` 集合的本地优先双向同步，可在“我的”中开关自动同步或立即手动同步
- 管理员可创建一次性分发密钥、设置到期时间、查看使用状态并随时收回
- 微信服务通知支持自选每日时间，并可组合今日任务、本周任务和滞留事项摘要
- 独立 Repository / Service 数据层，便于以后替换为远程 API

## 运行

1. 打开微信开发者工具。
2. 选择“导入项目”，目录指向本仓库根目录。
3. 使用测试号或在 `project.config.json` 中替换自己的 AppID。

数据首先保存在 `planote_items_v1` 这个本地 Storage 键中。获得同步权限的微信账号会通过 `planoteSync` 云函数，将数据同步到云环境 `my-day-d2g6hzuuw3b26a7d1` 的 `items` 集合。

## 同步服务配置

1. 上传并部署 `cloudfunctions/planoteSync`，选择云端安装依赖。
2. 给云函数配置环境变量 `SYNC_ACCESS_KEY_HASH`，值为验证密钥的 SHA-256 小写十六进制摘要。
3. 将 `items` 集合权限设置为“仅管理端可读写”，禁止小程序端绕过云函数直接访问。

首次使用环境变量对应主密钥验证的微信账号会成为同步管理员。管理员可以在“我的 → 分发密钥管理”中创建多把一次性密钥并设置有效期；每把密钥只能绑定一个微信账号。管理员可查看密钥用途、尾号、有效期和使用状态，也可随时收回。原始分发密钥只在创建时显示一次，云端仅保存不可逆摘要。密钥到期或收回后，对应账号将停止云同步，但本机数据不会丢失。连续输入错误五次会暂停验证十五分钟。

## 每日通知配置

1. 微信订阅消息使用“日程提醒”模板（编号 571）：`thing2` 提醒内容、`thing31` 任务名称、`time38` 截止时间、`thing8` 紧急度、`thing11` 备注。
2. 部署 `cloudfunctions/planoteNotify`，并确认 `planoteDailyReminder` 定时触发器已创建。该触发器每 5 分钟检查一次到点提醒。
3. 管理员进入“我的 → 每日通知”，填入订阅消息模板 ID。
4. 用户在同一页面选择提醒时间和内容，并通过微信订阅弹窗授权。

普通小程序通常只能使用一次性订阅消息：每同意一次只可发送一条服务通知，发送后需要再次续订。只有符合微信指定公共服务类目的长期订阅模板才可以持续发送；不要为普通模板开启“长期订阅模板”。
